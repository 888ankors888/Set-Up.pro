# Модуль «Питание» (React + TypeScript)

Готовый блок учёта питания: форма добавления блюд, расчёт калорий и БЖУ, итоги дня, цели, адаптивная вёрстка, светлая/тёмная тема. Без внешних зависимостей (только React 18+).

## Подключение
Скопируйте папку `src/Nutrition` в проект и используйте:

```tsx
import { NutritionBlock } from './Nutrition';

<NutritionBlock
  title="Питание"
  initialGoals={{ kcal: 2200, protein: 140, fat: 70, carbs: 250 }}
  onTotalsChange={(totals, date) => console.log(date, totals)}
/>
```

Стили — CSS Modules (`Nutrition.module.css`), поддерживаются Vite, Next.js и CRA из коробки.

## Пропсы
| Проп | Тип | По умолчанию | Описание |
|---|---|---|---|
| `title` | `string` | `"Питание"` | Заголовок блока |
| `initialGoals` | `{kcal, protein, fat, carbs}` | 2200 / 140 / 70 / 250 | Дневные цели |
| `persist` | `boolean` | `true` | Хранить данные в localStorage |
| `storageKey` | `string` | `"nutrition-block"` | Префикс ключей localStorage |
| `foodDatabase` | `FoodPreset[]` | встроенный справочник (30 продуктов) | Свой справочник для автодополнения |
| `onTotalsChange` | `(totals, date) => void` | — | Колбэк при изменении итогов дня |
| `className` | `string` | — | Доп. класс для корня |

## Возможности
- Автодополнение из справочника (стрелки ↑↓, Enter, Esc), ручной ввод БЖУ на 100 г.
- Автоподсчёт калорий по БЖУ (4/9/4 ккал/г) или ручной ввод калорийности.
- Быстрый выбор веса (50–250 г), предпросмотр порции в реальном времени.
- Валидация: вес 1–5000 г, каждое значение БЖУ 0–100 г, сумма ≤ 100 г.
- Группировка по приёмам пищи, редактирование и удаление записей, очистка дня.
- Навигация по дням, кольцо калорий, прогресс БЖУ, распределение энергии в %.
- Адаптивность: 1 колонка на мобильных, 2 колонки от 900px (форма закреплена справа).
- Темизация через CSS-переменные `--nb-*`, тёмная тема по `prefers-color-scheme`.

## Структура
```
Nutrition/
  index.ts             — публичный экспорт
  NutritionBlock.tsx   — основной блок (сводка, цели, список)
  AddFoodForm.tsx      — форма добавления/редактирования
  useNutrition.ts      — хук состояния и хранения
  nutrition.ts         — чистые функции расчёта
  foodDatabase.ts      — справочник продуктов и поиск
  types.ts             — типы
  Nutrition.module.css — стили
```

Хук `useNutrition` и функции из `nutrition.ts` можно использовать отдельно — например, чтобы хранить данные на сервере вместо localStorage.
