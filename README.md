# Set-Up — текстовый ввод через GigaChat

Пакет подготовлен на основе загруженного Index.html и актуального backend/main.py.
Не содержит ключей или паролей. В GitHub и Render из этого ответа не опубликован.

## Файлы для замены в существующем репозитории
- index.html — исходное приложение с новой формой на экране «Сегодня».
- backend/main.py — существующий сервер плюс CORS для GitHub Pages и localhost:8000, а также страница /app.
Остальные файлы backend и переменные Render остаются без изменений.

После публикации обеих замен дождитесь успешного развёртывания Render и GitHub Pages.
Единственный адрес сайта: https://888ankors888.github.io/Set-Up.pro/

Не переходите на другой адрес, если хотите сохранить доступ к текущему локальному дневнику: хранилище у разных адресов раздельное. Для переноса используйте JSON-резервную копию из профиля.
При открытии index.html двойным кликом форма доступна для просмотра, но API-запросы из file:// не разрешены CORS. Используйте опубликованный сайт либо локальный сервер: python -m http.server 8000.

## Пользовательский сценарий
1. Заполнить профиль, если его ещё нет.
2. На экране «Сегодня» найти «Что вы ели?» и ввести описание.
3. Нажать «Доступ к ИИ» и ввести только APP_ACCESS_TOKEN. Не вводить ключ GigaChat.
4. Нажать «Разобрать». Каждому продукту вручную выбрать соответствующую запись каталога.
5. Указать массу съедобной части в граммах. Штуки автоматически в граммы не переводятся.
6. Проверить уточнения модели, при необходимости изменить описание и повторить разбор.
7. Подтвердить проверку и сохранить. Продукты записываются отдельными строками в выбранный день.

КБЖУ рассчитываются по существующему усреднённому каталогу, а не генерируются моделью. Если подходящей записи нет, используйте существующий ручной ввод с данными упаковки. Стандартный вес яйца не подставляется.
Пароль API хранится в памяти страницы, исчезает при перезагрузке и не входит в резервную копию. Это не многопользовательская авторизация. Публичный коммерческий запуск требует отдельной защиты и проверки тарифа GigaChat.
Старые фотоанализ и ИИ-отчёты остаются зависимыми от среды Claude и не перенесены на GigaChat.
