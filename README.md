# Set-Up.pro — объединение страниц

В комплекте полный обновлённый index.html на основе предоставленного файла.
Спорт открывается внутри индекса, без iframe, отдельного HTML и редиректов.
Интерфейс и обработчики тренировок встроены в index.html.
Сохранена зависимость от существующих data-store.js и workouts/store.js.
Анкета спорта использует существующие goals-*.js; её копия не создаётся.
Питание и другие разделы не переписывались с нуля.
Автоматическая очистка данных не добавлена: разрешение на очистку не требует её выполнения.
ИИ-генерация тренировок, как и раньше, недоступна; кнопка явно отключена.

Изменения репозитория:
- заменить index.html;
- удалить workouts.html;
- остальные файлы оставить без изменений.

Для применения извлеките архив ВНЕ репозитория, перейдите в корень клонированного
Set-Up.pro и запустите Python-скрипт apply_changes.py из извлечённого архива.
Скрипт проверит исходные Git blob SHA и откажется перезаписывать изменённые файлы.
Затем проверьте git diff. Скрипт не создаёт коммит и ничего не отправляет на GitHub.

Проверки: 22 встроенных JS-скрипта — синтаксис Node.js без ошибок;
13 изолированных браузерных проверок модуля спорта — успешно.
Это не полное E2E-тестирование опубликованного сайта: хранилище было тестовым.
