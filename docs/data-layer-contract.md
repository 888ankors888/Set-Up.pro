# Задача №6: основа слоя данных (пакет 1)

Это подготовительный модуль, а не завершённая миграция. Он НЕ подключён к index.html или workouts.html; существующие обращения к localStorage не заменены. Импорт/экспорт приложения и доменные валидаторы этим пакетом не изменяются. Задача №6 остаётся открытой.

## API
- `createStore({storage, validate})`: обязательны явно переданное хранилище и синхронный доменный валидатор. Валидация всех разделов должна быть подключена интеграцией; пример в тестах не является валидатором приложения.
- `read() -> {raw, state}`: чтение без записи. Отсутствующий ключ возвращает null; повреждение, отказ доступа и ошибка валидации различаются кодами ошибок.
- `commit(next, snapshot)`: проверяет состояние и исходный снимок, пишет только `nt1`, затем уведомляет подписчиков. Явная первичная инициализация возможна через снимок отсутствующего ключа; автоматической нет.
- `update(change)`: перечитывает состояние, изменяет независимую копию синхронным mutator, затем вызывает commit. Callback возвращает undefined.
- `subscribe(listener) -> unsubscribe`: независимая копия для каждого подписчика. Исключение UI не превращает успешную запись в ошибку сохранения; количество ошибок возвращается в listenerErrors. Вложенные записи при уведомлении запрещены.
- `attachStorageEvents(window) -> detach`: реагирует на nt1 и clear; перечитывает хранилище вместо доверия payload события. Обработку ошибок внешнего обновления интерфейс должен определить при интеграции.

## Ограничения
Сравнение raw обнаруживает уже изменившийся снимок, но не является атомарной транзакцией между вкладками. Остаются гонки между сравнением и записью и ABA-сценарий. Нельзя обещать отсутствие потерянных обновлений до реализации и браузерной проверки общей политики координации всех писателей. Пока старые писатели не переведены, даже кооперативная блокировка нового модуля недостаточна.

JSON-совместимость проверяется до сериализации: NaN, Infinity, undefined, функции, Date, разреженные массивы и циклы отклоняются, а не теряются молча. Неизвестные JSON-поля сохраняются; правила их совместимости и поддерживаемые версии определяет обязательный validate. Это не разрешение принимать неподдерживаемые схемы.

Ключи темы и старых тренировок не читаются и не очищаются. Модуль не вызывает activateLegacyReset, removeItem или clear. Он не меняет S и не показывает toast: при интеграции S обновляется только после успешного результата commit/update.
